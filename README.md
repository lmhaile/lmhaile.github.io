# Portfolio

This github repository is a portfolio of my research work, adapted from Fabio Fehr's [template](https://github.com/FJFehr/fjfehr.github.io/) and Tristan Myles's [training](https://github.com/tristan-myles/edam_women_in_health_website_tutorial.git) for the Ethiopian Data Analytics and Modelling Consortium. I've made some stylistic changes (removing blogs and updating the aesthetic) with the help of Copilot.

Feel free to clone and use as a template if needed. More documentation found in the links above.
